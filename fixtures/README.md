# Fixtures

Fixtures are deterministic, synthetic, and redacted examples for future validation work. They are designed to test prompt contracts, schema shape, no-leakage behavior, safety routing, and report generation without storing real intimate conversation content.

## Privacy rules
- Do not add real names, phone numbers, screenshots, or explicit intimate details.
- Do not paste real private transcripts.
- Keep allegations framed as claims inside the artifact, not verified facts.
- Keep raw input fixtures separate from expected derived analysis.
