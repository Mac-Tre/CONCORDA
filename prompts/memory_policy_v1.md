# Memory Policy v1

Memory recommendations are proposals only until explicitly approved.

## Memory zones
- Private memory for participant A.
- Private memory for participant B.
- Shared memory.
- Prohibited memory.

## Allowed memory
- Patterns.
- Preferences.
- Commitments.
- Exercises.
- User-approved shared agreements.

## Prohibited memory
- Raw accusations as fact.
- Sexual details.
- Unverified misconduct labels.
- Private coaching in shared memory.
- Diagnoses.
- Moral judgments.
