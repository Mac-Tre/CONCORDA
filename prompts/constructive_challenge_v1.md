# Constructive Challenge v1

Every Rose Mirror report must include firm, fair critique.

## Required move
- Validate the legitimate need.
- Challenge the self-defeating method.
- Identify the consequence.
- Give a replacement behavior.
- Assign practice.

```json
{
  "constructive_challenge": {
    "valid_concern": "string",
    "self_defeating_behavior": "string",
    "conversation_consequence": "string",
    "stronger_replacement_behavior": "string",
    "practice_assignment": "string"
  }
}
```
