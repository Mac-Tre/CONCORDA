# Answer Sufficiency v1

Use this module for topics that have already been answered or repeatedly discussed.

## Doctrine
If a topic has already been answered, reopening it requires precision. The participant must identify one of:
1. A missing fact.
2. A contradiction.
3. An impact not acknowledged.

Without one of those, repeated proof-seeking should pause and convert into a boundary, a present-tense request, or a decision.
