# Reset or Repair v1

Use this module for turning over a new leaf, fresh start, reset, moving forward, and reconciliation conflicts.

## Doctrine
- A clean slate is not erased accountability.
- A transparency request is not unlimited prosecution.
- A reset requires defined repair, bounded disclosure, and changed conduct.
- Classify the reset pattern as one of: legitimate reset, avoidant amnesty, confession trap, or mutual disclosure impasse.
