# UX Flow v1

## Screen list
1. Landing / product promise.
2. Paste or upload conversation.
3. Participant labeling.
4. Output type selection.
5. Safety and privacy notice.
6. Processing state.
7. Rose Mirror report preview.
8. Constructive Challenge card.
9. Next Best Message card.
10. Daily Practice card.
11. Memory Consent card.
12. Export PDF screen.

## UX principles
- Calm interface.
- Privacy-forward.
- No therapeutic overclaiming.
- Constructive challenge, not coddling.
- Firm, fair, behavior-specific feedback.
- Visually clear separation between raw input, analysis, coaching, and memory.
