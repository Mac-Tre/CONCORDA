# Safety and Privacy Policy

Concorda is not emergency support. If someone may be in immediate danger, the product should direct them to local emergency resources or trusted support instead of generating a relationship repair plan.

## Safety mode triggers
Safety mode must trigger when an artifact indicates:
- Threats.
- Coercion.
- Intimidation.
- Stalking.
- Physical violence.
- Sexual coercion.
- Self-harm.
- Fear-based compliance.
- Isolation or monitoring.

If safety mode triggers, Concorda must not create a couples repair plan. It should prioritize immediate safety, boundaries, support options, and low-risk next steps.

## No-leakage rule
Participant-specific coaching must never be shown to the other participant. Private memory, inferred vulnerabilities, private report content, and private recommendations are scoped only to the participant who authorized them.

## Memory rules
- **Private memory:** participant-specific patterns, preferences, commitments, and exercises visible only to that participant.
- **Shared memory:** user-approved agreements that both participants have consented to share.
- **Prohibited memory:** raw accusations as fact, sexual details, unverified misconduct labels, diagnoses, moral judgments, and private coaching in shared memory.
- **Consent requirement:** no memory is saved unless a participant explicitly approves the proposed memory update.

## Data minimization
Concorda should avoid storing sensitive details. It should store patterns and commitments rather than raw accusations, and it must allow deletion and revision in any future implementation.
