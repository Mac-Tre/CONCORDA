# Concorda Brand System (v1)

This package translates the provided brief into production-ready brand guidance and starter assets.

## 1) Core Brand
- **Brand name:** Concorda
- **Internal voice:** Corda
- **Primary line:** **Turn conflict into common ground**
- **Positioning:** Concorda helps couples turn disagreement into understanding, and understanding into a stronger future.

## 2) Meaning System
The mark and system should consistently signal:
- connection
- mediation
- fairness
- calm structure
- movement toward alignment
- longevity

## 3) Logo Concept
The logo is built from two rounded speech-bubble forms that face each other.

### Readings at once
- subtle heart
- bridge between sides
- infinity-style continuity loop

### Symbol semantics
- left form = cool/calm voice
- right form = warm/engaged voice
- overlap = shared understanding
- tails = minimal, integrated, rounded

## 4) Lockups Delivered
- `brand/logo/concorda-icon.svg` (icon-only)
- `brand/logo/concorda-horizontal.svg` (icon + wordmark)
- `brand/logo/concorda-stacked.svg` (icon + wordmark + optional tagline line)

## 5) Shape Rules
### Do
- rounded geometry
- medium/thick strokes
- clean silhouette
- balanced negative space

### Don’t
- sharp points
- aggressive diagonals
- competitive/judgment symbols (gavels, scales, trophies, crowns, versus marks)

## 6) Color System
| Token | Hex | Role |
|---|---|---|
| Deep Slate | `#24364C` | trust, dark backgrounds |
| Calm Teal | `#5FA9A2` | listening, balance |
| Warm Coral | `#EE7B6A` | warmth, engagement |
| Soft Cream | `#F7F4EE` | light background base |
| Neutral Mist | `#DCE3E6` | UI surface/dividers |
| Text Charcoal | `#2D3742` | primary text |

## 7) Typography Direction
Use a rounded geometric sans with:
- humanist warmth
- strong mobile legibility
- stable lowercase rhythm
- soft terminals

## 8) Tagline System
### Primary
- **Turn conflict into common ground**

### Approved alternates
- Make disagreement useful
- Communicate to last
- Where couples learn to argue well
- Healthier conflict. Stronger connection.

## 9) App Icon Notes
Use a rounded-square container with high-contrast two-form symbol.
- Avoid tiny details and hairlines
- Keep center silhouette legible at small sizes

### Modes
- dark mode primary: slate background + teal/coral forms
- light mode support: cream background + slate/dual-color forms

## 10) Non-Negotiable Framing Rule
Concorda must never imply one partner defeating the other. Every asset should reinforce shared progress and stronger partnership.
